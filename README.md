# 💘 썸루트 (SumRoute) — 리얼 데이트 시뮬레이터 MCP 서버

실제 지도 데이터(카카오맵)를 기반으로 데이트 코스를 미리 리허설해보는
MCP(Model Context Protocol) 게임 서버입니다.

## 어떻게 동작하나요?

- **서버(이 코드)**: 게임의 "심판" 역할
  - 세션 / 호감도 / 라운드 상태 기억
  - 카카오맵에서 실제 장소 검색
  - 점수 규칙 집행 (클램핑, 합산, 은닉)
- **클라이언트 LLM**: 게임의 "배우" 역할
  - 데이트 상대 페르소나 연기
  - 사용자의 선택이 상대 취향에 맞는지 자연어로 판정

장소 검색·점수 계산처럼 정확해야 하는 부분은 서버가 담당하고,
자연어 이해가 필요한 취향 판단은 LLM에게 맡기는 구조입니다.

## 게임 흐름

1. `start_date` — 세션 생성 (상대 성별 / 성격·취향 / 관계 단계 / 만남 장소 입력)
2. 각 라운드마다:
   - `search_nearby` — 근처 실제 장소 자동 검색 (식사 → 액티비티 → 카페·소품샵 → 마무리)
   - 사용자가 선택
   - `make_choice` — 선택 기록 + 호감도(숨김 점수) 갱신
3. `get_result` — 최종 코스 요약 + 성적표(S~F) + 플랜B 제안

## 주요 특징

- 카카오 로컬 API 기반 실제 장소 검색 (목업 없음, API 키 필수)
- 만남 장소 기준 반경 내(기본 1.2km, 최대 2.0km)에서만 코스 구성
- 같은 세션 내 중복 장소 노출 방지, 분야(display_family)별 선택지 다양화
- 호감도는 평소 비공개, 변동폭이 클 때만(`±8` 이상) 이펙트로 노출
- 선물 이벤트는 "살까 말까"가 아닌 표현 방식(조용히 챙기기, 직접 표현 등) 중심
- 돌발 이벤트(비, 웨이팅 등)는 발생 자체로 점수가 바뀌지 않고, 사용자 대응에 따라 반영

## 실행 방법

```bash
KAKAO_REST_API_KEY=<카카오 REST API 키> python server.py
```

- API 키가 없으면 서버가 시작되지 않습니다 (fail-fast).
- Transport: HTTP (`http://<host>:<port>/mcp`), 기본 포트 8000
- 로컬 stdio 테스트 시 `mcp.run()`으로 변경해서 사용 가능

## 환경변수

| 변수명 | 기본값 | 설명 |
|---|---|---|
| `KAKAO_REST_API_KEY` | (필수) | 카카오 REST API 키 |
| `PORT` | 8000 | 서버 포트 |
| `NEARBY_RADIUS_M` | 1200 | 기본 검색 반경(m) |
| `NEARBY_RADIUS_MID` / `NEARBY_RADIUS_MAX` | 1600 / 2000 | 후보 부족 시 확장 반경 |
| `AUTO_KEYWORD_COUNT` | 3 | 라운드당 자동 검색 키워드 수 |
| `MAX_CACHE_ENTRIES` | 500 | 검색 결과 메모리 캐시 최대 개수 |

## 참고

- 세션 데이터는 서버 메모리에만 저장되며, 재시작 시 사라집니다. (실서비스는 Redis 등 외부 저장소 권장)
- 예상 비용은 검증하지 않으므로 결과에서 구체적 금액을 단정하지 않습니다.
